# Stickman Studio

استودیوی تحت وب ساخت و ویرایش کاراکتر استیکمن.

## اجرای محلی

سه فایل `index.html`، `style.css` و `app.js` را در یک پوشه قرار بده و `index.html` را در مرورگر باز کن. برای بهترین تجربه می‌توانی از افزونه Live Server در VS Code استفاده کنی.

## ساختار

- `index.html`: ساختار صفحه و بوم کاراکتر
- `style.css`: ظاهر واکنش‌گرا و چیدمان موبایل
- `app.js`: ریگ، پوز، انیمیشن، فیزیک، ذخیره‌سازی و خروجی‌ها

پنل «تجهیزات» از پنل «ظاهر کاراکتر» جدا شده است تا فضای اصلی برای کار روی خود کاراکتر خلوت بماند. نسخهٔ شروع با کاراکتر بدون تجهیزات باز می‌شود.
