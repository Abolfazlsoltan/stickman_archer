# Stickman Studio — Character Lab

استودیوی دوبعدی طراحی آدمک با رابط فارسی، ریگ استخوانی، پوزهای آماده و حرکت‌های رویه‌ای.

## قابلیت‌ها

- سه سبک ظاهری، تنظیم رنگ بدن/لباس/پوست/مو و تغییر تناسبات اندام
- کنترل جداگانهٔ زاویهٔ ستون فقرات، سر، شانه‌ها، آرنج‌ها و بالا آوردن پا
- حل‌کنندهٔ IK دو‌بخشی برای بازو و پا با حفظ طول استخوان‌ها
- حرکت‌های ایستادن، راه رفتن، دویدن، دست تکان دادن، گارد و حفظ تعادل
- انیمیشن‌های کوچک و پیوسته برای تنفس، سر، شانه‌ها و دست‌ها
- قفل محل پای تکیه‌گاه در فاز اتکا، گرانش، پرش و برخورد با زمین
- کنترل اصلاحی تعادل با تخمین مرکز جرم و انتقال لگن/بالاتنه
- خروجی PNG، SVG و فایل پروژهٔ JSON
- رابط ساده و واکنش‌گرا برای موبایل و دسکتاپ

## ساختار فایل‌ها

- `index.html`: رابط برنامه
- `style.css`: طراحی و چیدمان واکنش‌گرا
- `app.js`: رندر صحنه، کنترل‌ها و انیمیشن‌های رویه‌ای
- `rig.js`: اسکلت، زنجیره‌های استخوانی، IK و تخمین مرکز جرم
- `physics.js`: گرانش، پرش، فرود و چرخهٔ تماس پا با زمین
- `tests/rig.test.js`: آزمون‌های طول استخوان، تماس پا و گرانش

## اجرا

فایل `index.html` را در مرورگر باز کن یا از Live Server استفاده کن. برای اجرای آزمون‌ها با Node.js:

```bash
node tests/rig.test.js
```

## نکتهٔ فنی

این نسخه یک انیماتور دوبعدی مبتنی بر IK و فیزیک گرانش/تماس زمین است. کنترل تعادل از تخمین مرکز جرم و اصلاح موقعیت بدن استفاده می‌کند؛ شبیه‌سازی کامل دینامیک چندجسمی سه‌بعدی یا موشن‌کپچر نیست.
