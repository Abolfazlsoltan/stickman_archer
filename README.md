# Stickman Studio

استودیوی تحت وب برای ساخت و ویرایش کاراکتر استیکمن؛ با تمرکز بر ریگ کامل، پوزسازی، انیمیشن و شخصی‌سازی ظاهری.

## امکانات
- ریگ استخوانی با کنترل IK و FK و تنظیم مفصل‌ها
- پوزهای آماده، حرکت‌های پایه و تایم‌لاین فریم‌کلیدی
- فیزیک حرکت، گرانش، پرش، اصطکاک و محیط
- پنل مستقل لوازم ظاهری: شنل، کلاه‌خود، پر، کوله‌پشتی، محافظ شانه، مچ‌بند، دستکش، چکمه و کمربند
- ذخیره و بازیابی پروژه، خروجی SVG و PNG
- رابط فارسی و چیدمان واکنش‌گرا برای موبایل و دسکتاپ

## فایل‌ها
- `index.html`: ساختار رابط کاربری
- `style.css`: طراحی و چیدمان واکنش‌گرا
- `app.js`: منطق ریگ، انیمیشن، فیزیک و ذخیره‌سازی

## اجرای محلی
سه فایل اصلی را در یک پوشه قرار بده و `index.html` را در مرورگر باز کن. برای توسعه، VS Code و افزونه Live Server مناسب است.

## انتشار آنلاین
انتشار از طریق GitHub Actions و GitHub Pages انجام می‌شود. پس از فعال بودن Pages با منبع **GitHub Actions**، هر push به شاخه `main` نسخهٔ آنلاین را به‌روزرسانی می‌کند.
